- Started investigating on how to build a pipeline for train and test different models, and followed this pythorch documentation:
https://docs.pytorch.org/tutorials/intermediate/torchvision_tutorial.html#putting-everything-together


Setup:

- To setup, there was a need to build a new environment with conda to install all necessary libraries such as torchvision and pycocotools. It was also download to a specific directory all necessary python scripts necessary to run the pipeline. Initially there was a problem with pycocotools instalation, and that was the reason to create a isolated environment in conda, since python 3.12 on windows was not recognising pycocotools library.
- Tested first with a small dataset of 18 images of previously annotated multiphase images with brush labels to check if everything could run and to see the flow and how the process worked. Used also a maskrcnn_resnet50_fpn to test with default weights. Developed a Dataset Class to store the dataset, a get instance model function, the trainning loop and then a testing section.

Development:

- Reused part of the python code from https://docs.pytorch.org/tutorials/intermediate/torchvision_tutorial.html#putting-everything-together
